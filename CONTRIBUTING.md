# Contributing

Thanks for your interest in the extension.

- **Bugs and feature requests** go to the issue tracker here. Please include the browser and its version, and never post a real API key.
- **Pull requests** are welcome once the first release is out and the build is documented. Until then, an issue is the best place for a proposal.
- **Translations.** Corrections to the texts in `_locales` are welcome as pull requests once they exist; please say which language you are a native or fluent speaker of.
- **API questions** belong in the [API repository](https://github.com/flashcards-gg/api).
