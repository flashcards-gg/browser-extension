# Edge Add-ons: description per language

Partner Center asks for a description (250–10,000 characters) and the logo for every
language in the package. Paste each block into **Store listings → Details for <language>**;
the logo is `docs/store/edge-logo-300.png` (use **Duplicate this logo for all languages**).
Written by hand from the English text; the quoted menu and button names match `_locales/`.
