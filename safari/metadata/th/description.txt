เพิ่มการ์ดลงในชุดของคุณบน Flashcards.gg โดยไม่ต้องออกจากหน้าที่คุณกำลังอ่านใน Safari

เลือกคำหรือวลี กด Control ค้างไว้แล้วคลิก จากนั้นเลือก “เพิ่มลงใน Flashcards.gg” แบบฟอร์มเล็กๆ จะเปิดขึ้นบนหน้าเว็บเลย ข้อความที่เลือกจะเป็นด้านหน้าของการ์ด และชุดจะเป็นชุดที่คุณใช้ล่าสุด เขียนด้านหลัง หรือกด “อัตโนมัติ” เพื่อให้เขียนให้ แล้วกด “บันทึก” การ์ดจะปรากฏในชุดของคุณบนทุกอุปกรณ์ที่คุณใช้ Flashcards.gg

เริ่มต้นใช้งาน: เปิดแอป เปิด Flashcards.gg ในการตั้งค่า Safari › ส่วนขยาย จากนั้นคลิกปุ่ม Flashcards.gg ในแถบเครื่องมือของ Safari แล้ววางคีย์ API ส่วนตัวของคุณ

ส่วนขยายนี้ติดต่อกับ flashcards.gg เท่านั้น ข้อความที่เลือกจะถูกส่งไปที่นั่นเมื่อคุณกด “บันทึก” หรือ “อัตโนมัติ” และคีย์ API จะเก็บไว้ใน Safari บน Mac เครื่องนี้เท่านั้น ไม่มีการวิเคราะห์ข้อมูล

คุณต้องมีบัญชี Flashcards.gg และคีย์ API ส่วนตัว ซึ่งสร้างได้ในบัญชีของคุณที่ flashcards.gg (บัญชี › คีย์ API)
