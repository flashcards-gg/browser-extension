Safari에서 읽고 있는 페이지를 떠나지 않고 Flashcards.gg 세트에 카드를 추가하세요.

단어나 구문을 선택하고 Control 키를 누른 채 클릭한 다음 ‘Flashcards.gg에 추가’를 선택하세요. 페이지 위에 작은 양식이 열립니다. 선택한 텍스트가 이미 앞면에 들어가 있고, 세트는 마지막으로 사용한 세트입니다. 뒷면을 입력하거나 ‘자동’을 눌러 대신 작성하게 한 다음 ‘저장’을 누르세요. 카드는 Flashcards.gg를 사용하는 모든 기기의 세트에 나타납니다.

시작하려면: 앱을 열고 Safari 설정 › 확장 프로그램에서 Flashcards.gg를 켠 다음, Safari 도구 막대의 Flashcards.gg 버튼을 클릭하고 개인 API 키를 붙여넣으세요.

확장 프로그램은 flashcards.gg와만 통신합니다. 선택한 텍스트는 ‘저장’ 또는 ‘자동’을 누를 때 그곳으로 전송되며, API 키는 이 Mac의 Safari에만 저장됩니다. 분석 도구는 없습니다.

Flashcards.gg 계정과 개인 API 키가 필요하며, API 키는 flashcards.gg의 계정(계정 › API 키)에서 만듭니다.
