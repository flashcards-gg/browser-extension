Safari में जो पेज आप पढ़ रहे हैं उसे छोड़े बिना अपने Flashcards.gg सेट में कार्ड जोड़ें।

कोई शब्द या वाक्यांश चुनें, Control दबाकर उस पर क्लिक करें और “Flashcards.gg में जोड़ें” चुनें। पेज पर ही एक छोटा फ़ॉर्म खुलता है: चुना गया टेक्स्ट पहले से कार्ड का आगे का हिस्सा होता है और सेट वही होता है जिसे आपने पिछली बार इस्तेमाल किया था। पीछे का हिस्सा लिखें या “ऑटो” दबाएँ ताकि वह आपके लिए लिखा जाए, फिर “सहेजें” दबाएँ। कार्ड हर उस डिवाइस पर आपके सेट में दिखता है जहाँ आप Flashcards.gg इस्तेमाल करते हैं।

शुरू करने के लिए: ऐप खोलें, Safari सेटिंग्ज़ › एक्सटेंशन में Flashcards.gg चालू करें, फिर Safari टूलबार में Flashcards.gg बटन पर क्लिक करें और अपनी निजी API कुंजी चिपकाएँ।

एक्सटेंशन केवल flashcards.gg से बात करता है: “सहेजें” या “ऑटो” दबाने पर चुना गया टेक्स्ट वहाँ भेजा जाता है, और आपकी API कुंजी सिर्फ़ इस Mac के Safari में रहती है। कोई एनालिटिक्स नहीं।

आपको एक Flashcards.gg खाता और एक निजी API कुंजी चाहिए, जिसे आप flashcards.gg पर अपने खाते में बनाते हैं (खाता › API कुंजियाँ)।
